# Домашнее задание №9

Нужно было настроить RIP на третьей схеме из презентации и прислать скрин, где все соединения активны и горят зелёным.

## Результат

На приложенной схеме видны активные соединения между устройствами. Зелёные индикаторы подтверждают состояние интерфейсов, но сами по себе не доказывают правильность маршрутизации RIP.

## Как проверить маршрутизацию

1. Посмотреть активные интерфейсы командой `show ip interface brief`.
2. Проверить настройки RIP командой `show ip protocols`.
3. Выполнить `show ip route`: полученные через RIP маршруты помечены буквой `R`.
4. Проверить `ping` между компьютерами разных подсетей. При неудаче проверить маски, шлюзы и обратный маршрут.
